# 配置说明

[返回 README](../README.md) · [使用指南](usage.md)

## 启动方式

### 终端

安装 Node.js 22.13+（推荐 24）和 Codex CLI，在项目目录运行 `npm ci`、`codex login`、`npm start`。服务默认位于 <http://127.0.0.1:4318>，随终端进程结束而停止。开发时使用 `npm run dev`，后端文件变化后自动重启；前端修改后刷新页面即可。

### macOS 一键启动

双击项目中的 `start.command`，或执行：

```sh
./start.command
```

启动器检查 Node 和依赖，用文件锁避免重复启动，等待网页就绪后打开选材中心。服务在后台运行，重复启动会复用已有服务。`./start.command --no-open` 只启动和检查服务。

仓库提供 `start.command` 与其辅助脚本，不包含个人电脑上的桌面 `.app`。启动器固定使用端口 `4318`、项目的 `data/` 和根目录 `memroy.md`；自定义端口或数据目录请用 `npm start`。

## 环境变量

程序直接读取进程环境，**不会自动载入 `.env` 文件**。可在启动命令前设置变量，或通过终端环境导出。

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `PORT` | `4318` | HTTP 端口；监听地址固定为 `127.0.0.1`。 |
| `CODEX_BINARY` | 优先 `~/.local/bin/codex`，否则从 `PATH` 查找 `codex` | 指定 Codex 可执行文件。 |
| `STUDY_DATA_DIR` | 项目中的 `data/` | SQLite 和 API 配置的存储目录。 |
| `STUDY_MEMORY_FILE` | 项目根目录 `memroy.md`；设置 `STUDY_DATA_DIR` 时改为该目录下的 `memroy.md` | 单独指定学习记忆文件。 |
| `STUDY_OPEN` | 未设置 | 设置为 `1` 时，macOS 在服务启动后打开浏览器。 |

例如，在 macOS / Linux 终端中：

```sh
PORT=4319 STUDY_DATA_DIR="$HOME/.local/share/between-english" npm start
```

这个示例把数据库、API 配置和记忆文件放入独立目录。相对目录按启动时的工作目录解析，使用绝对目录更清楚。运行时临时文件仍位于项目中的 `work/runs/`。

## Codex 与模型选择

在「设置 → 模型与接口」获取可用模型，分别配置检索与阅读助手。模型发现使用本机 `codex app-server --stdio` 的 `model/list`，读取全部分页中的可见文本模型；不创建对话、不调用模型推理。

列表保存在本地，点击按钮重新查询；CLI 自身仍可能使用缓存。可选项代表 CLI 返回的模型，不等于逐个验证过额度与调用权限。获取失败保留已有列表，历史选择未出现在新列表时标为「上次选择」。

「Codex 默认」使用 CLI 默认模型。「沿用检索模型」仅沿用模型，阅读助手的 Effort / Fast 仍独立配置。可选的思考强度和 Fast 支持取决于模型目录中的能力信息。默认沿用模型思考强度，Fast 关闭；任务入队时固定配置，之后修改只影响新任务。

推荐方向固定使用 `gpt-6-luna` Fast 和可用的最低思考强度。若账户没有该模型或其能力信息，重新推荐会提示失败；普通选材仍使用所选检索模型。

## 自定义 API

在「设置 → 模型与接口 → 阅读助手」选择「自定义 API」，填写接口地址、API Key 和模型名称。例如地址可为 `https://api.example.com/v1`。可以获取模型列表，也可以手动填写模型 ID；保存后生效，切回 Codex 会保留 API 配置。

适配 OpenAI 兼容协议：

- 模型发现：`GET /models`。
- 讲解、翻译、生词释义、出题和批改：`POST /chat/completions`。
- Effort：选定后发送 `reasoning_effort`。
- Fast：开启后发送 `service_tier: "priority"`。

默认不发送 Effort / Fast 参数。供应商未提供能力信息时，可手动选择并测试兼容性；模型列表本身不保证所有模型都支持文本对话。原生 Anthropic 等其他协议暂未适配。

「测试连接」只发送简短测试请求，不发送文章或学习记忆。正式阅读任务会发送相关原文和问题，开启个性化时也会发送所需记忆摘要。后端严格校验返回结构，不保存格式错误或截断的结果；失败后不会自动切换供应商或重试计费请求。

单词和文章检索仍由 Codex 执行。自定义 API 只服务阅读助手，不替代真实搜索及来源校验。

### 密钥保存

密钥由本地后端保存，不返回网页，也不写入学习记忆或 SQLite：

- `data/api-provider.enc`：使用 AES-GCM 加密的 API 配置。
- `data/api-provider.key`：用于解密配置的本机密钥。

使用自定义数据目录时，两者都在该目录下。文件权限限制为当前用户读写；同时持有这两个文件即可解密配置，备份时应保护整个目录。

同一地址下留空密钥会保留已存密钥，更换地址不会沿用旧密钥。切回 Codex 后也可展开 API 配置并清除密钥。远程地址要求 HTTPS；本机回环地址可用 HTTP，且可不填密钥。API 请求不跟随重定向。

## 数据与备份

| 位置 | 内容 |
| --- | --- |
| `data/study.sqlite` 及其 WAL 文件 | 单词、词表、文章、学习事件、设置与任务记录。 |
| `memroy.md` | 手写学习备注和自动生成的学习摘要。 |
| `data/api-provider.enc`、`data/api-provider.key` | 自定义 API 配置与解密密钥。 |
| `data/launcher.log` | 使用一键启动器时的服务日志。 |
| `work/runs/` | 临时模型任务文件，任务结束时清理。 |

备份前停止服务，再复制整个数据目录及实际使用的 `memroy.md`。不要在运行中只复制 SQLite 主文件。恢复时在服务停止状态下放回对应位置。

数据库、个人记忆、密钥、日志和临时文件不应进入版本库。默认位置已被 `.gitignore` 排除；若在项目内另设存储路径，也应自行加入忽略规则并检查待提交文件。

删除记忆文件后会以默认备注重建摘要，因此修改或删除前应备份自己的备注。服务退出时未完成的任务，下次启动显示为中断，可手动重试。

## 等待与诊断

- 单词、文章及统一选材：有新事件时继续等待，最长 10 分钟；连续 4 分钟无新事件则停止。
- 推荐方向：最长 2 分钟；连续 1 分钟无新事件则停止。
- 其他 Codex 任务：最长 4 分钟，可主动取消。

连接恢复后正常完成的结果仍会校验并保存。任务诊断保留模型设置、耗时、搜索次数、重连次数和错误类别，不保存原始错误输出或凭据。

## 调用边界

本应用仅绑定 `127.0.0.1`，校验 Host、Origin 和同源请求令牌，不适合作为直接暴露到公网的多人服务。

Codex 以无交互、临时会话和只读权限运行，禁用 shell、应用连接、插件、浏览器操作、全局记忆和 hooks，并忽略用户模型配置。认证继续由 CLI 管理；应用提取必要的学习摘要放入请求，不授权模型读取本地个人文件。

筛选启用实时联网搜索，结果必须有真实 `web_search` 记录，且来源 URL 出现在搜索结果中。这只验证检索来源，难度和讲解仍需结合原文判断。讲解只使用提供的文章上下文。

文章抓取屏蔽私有地址，并逐次校验重定向和 DNS、固定连接地址。若本地代理返回 `198.18/15` 合成地址，会通过 Cloudflare HTTPS DNS 获取公开地址后重新校验，不把合成地址加入允许列表。单次正文提取最多 45 秒；文章内容以纯文本显示。

Codex 调用使用当前登录账户的额度，自定义 API 使用对应供应商的账户额度。应用不读取其他应用、浏览记录或个人文件；CLI 登录凭据和已保存 API 密钥不返回前端。
