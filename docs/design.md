# 纸间·森绿

句。间的默认主题。像一本可以交互的书：暖纸白承载阅读，森林绿指引操作，少量杏金标记值得留下的内容。

| 用途 | 颜色 | CSS 变量 |
| --- | --- | --- |
| 页面背景 | `#F7F5EF` | `--bg` |
| 卡片、阅读区 | `#FFFDF8` | `--paper` |
| 正文 | `#292F2C` | `--ink` |
| 次要文字 | `#69736B` | `--muted` |
| 主要操作 | `#2F6653` | `--green` |
| 选句、当前项 | `#E5EEE6` | `--green-soft` |
| 生词、已收藏内容 | `#F3E2B8` | `--gold-soft` |
| 分隔线 | `#E2E5DC` | `--line` |

- 阅读正文、卡片与助手回复保持柔白底。普通按钮和学习完成状态用绿色；杏金仅用于生词标签、已收藏按钮和收藏的单词。
- Logo 保留「句。间」的完整文字；「句」「间」用墨灰，中间的「。」用森林绿。小尺寸图标沿用 `b.`。
- 保留短英文 slogan、衬线阅读字体和充足留白，不增加主题解释到学习界面。
- 小字在浅绿或杏金底上使用墨灰、森林绿或深金棕 `#6A5128`。灰绿小字仅用于纸白等中性浅底。
- 表单边框使用灰绿 `#89948A`，焦点使用森林绿；暖灰仅作结构分隔。错误保持红色，并配文字说明。
- 学习热力图沿用绿色深浅表达数量，具体数值由悬浮和详情提供。收藏状态同时保留文字与 `aria-pressed`，不只依赖颜色。

样式变量集中在 `public/style.css`。手机与桌面共用同一主题，不额外加入配色切换入口。
