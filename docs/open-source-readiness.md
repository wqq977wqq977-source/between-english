## 已修复

| 问题 | 改后行为 | 回归覆盖 |
| --- | --- | --- |
| Codex 错误消息类型异常可能使整个 Node 服务退出 | 将异常事件转成单个任务的受控错误 | 畸形 `error` / `turn.failed` 消息、进程存活 |
| HTTP 网络分包可能破坏中文和 emoji | 按字节收集后严格解码 UTF-8，拒绝非对象 JSON 与超限输入 | 多字节拆包、非法编码、JSON 根类型、字节上限 |
| 已有宽权限目录下的数据库及辅助文件可能被其他本机用户读取 | 数据库、WAL、SHM、journal 收紧到 `0600`，新目录为 `0700`；保留已有父目录权限 | 旧库重开、活跃辅助文件、符号链接指向的真实数据库 |
| 批改完成后显示的答案可能来自尚未提交的草稿 | 已批改题只显示服务器实际评分的答案 | 批改期间修改选择题和简答题、未批改草稿保留 |
| 文章 A 的读完响应可能把后来打开的 B 标为读完 | 回写仅作用于原文章 | 留在原文、切换文章、返回书架 |
| macOS 启动器覆盖调用者的 Node 选择，且其他系统可能先启动后报错 | 保留 PATH 顺序，非 macOS 提前退出并提示终端启动 | 自选 Node、含空格和 `#` 的路径、无副作用退出 |

## 已知边界

- 原生 Windows、WSL2 的浏览器与登录流程未单独验收；`start.command` 仅支持 macOS。
- 真实调用验证使用应用优先选择的 CLI 0.159.3；终端 PATH 中的 0.160.0 仅核对帮助参数。不同账户的模型可用性、额度及未来 CLI 协议可能不同；一次示例与协议替身测试不能证明所有真实供应商调用可用。
- 自定义 API 的协议与故障处理已用替身测试，未对每个外部供应商做计费请求。
- 本应用没有多人身份验证与权限隔离，不应直接作为公网服务部署。
- 默认学习记录与个性化均开启；需要的原文、问题和记忆摘要会发送给所选模型。文档与设置页已说明这一行为。
